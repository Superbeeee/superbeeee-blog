I grew up watching my grandmother turn prayer beads while reciting sutras, using a small counter to track each chant. Years later I picked up the practice myself, and the existing apps for tracking recitation either drowned the experience in flashy UI or forced the wrong mental model. Across two weekends I built my own — ideating the screens with Claude Design, locking the spec down with openspec, and shipping the React Native + Expo build with Claude Code — finally running it on my own iPhone.

The other motivation was to put **SDD (Spec-Driven Development)** to a real test: write the spec first, then let AI implement strictly against it, and see whether it actually beats vibe coding on stability and traceability.
