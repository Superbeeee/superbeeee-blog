## 小開箱銀座旗艦店✨

其實下午就有先去店裡逛逛，抵達時需要排隊入場，大概排了三十分鐘，沒有想像的久。

{% asset_img 03-flagship-front.jpg %}

<figure>
{% asset_img 04-queue-sign.jpg %}
<figcaption>排隊起點的小告示牌</figcaption>
</figure>

一進門就可以看到 On 的經典標語『 **Dream On.** 』身為粉絲真的大興奮，馬上拍張照 <3

{% asset_img 05-dream-on.jpg %}

一樓都是鞋子區，二樓除了鞋子外也有服飾，但可能因為生意太好很多貨品都沒什麼尺寸。背包或是配件，則要主動詢問一下有沒有現貨，並不會所有東西都擺出來。

{% asset_img 06-store-1f.jpg %}

{% asset_img 07-store-2f.jpg %}

來的時間有點不太對，因為隔天預計會出新一批衣款，有點撲空了。

試穿了一件網球系列的運動衫，更衣室很大，牆面材質工業水泥感摸起來有點割手要小心 XD。

<figure>
{% asset_img 08-shopping.jpg %}
<figcaption>旗艦店購物初體驗～</figcaption>
</figure>

最後買了 On 的鞋袋。如果挑選完商品還想逛，可以將商品給店員放在櫃檯，會獲得號碼牌，想結帳時再去櫃檯一起做結帳，蠻方便的。

{% asset_img 09-shoe-bag.jpg %}

## Tokyo On Run Club 實體活動 試跑 On Cloudmonster 3 ✨

在東京馬 Expo，就已經先看過 On Cloudmonster 3（以下簡稱雲怪 3）。日本應該是配合東京馬的人氣是第一個先上市的國家，原本以為只是一般的城市跑活動，到現場才知道是試跑活動，好讚～

晚上到店裡時依然是大排長龍，和門口店員出示報名截圖就直接進店了。下午看樓層介紹時就注意到神秘的 B1 Run Club，似乎沒有對外開放。藉由這次 ORC 活動來看看這層樓的神秘面紗 ^0^

{% asset_img 10-orc-night-queue.jpg %}

{% asset_img 11-b1-entrance.jpg %}

B1 空間沒有一二層來得大，大部分應該還是員工區。開放的空間擺放了這次的主角 **On Cloudmonster 3**。中間為活動空間，旁邊則有更衣室及置物櫃，還有簡單的健身區。置物櫃可以設定密碼很貼心，但因為怕忘記密碼就用預設的^^a。想來體驗實體活動的跑友可以善用一下。

<figure>
{% asset_img 12-locker.jpg %}
<figcaption>方便的寄物櫃！</figcaption>
</figure>

{% asset_img 13-cloudmonster-3.jpg %}

初次穿上雲怪 3，覺得改進幅度非常顯著。因為之前在試穿第二代時，覺得腳後跟的穩定性沒有很好，如果遇到不平的路或是突起物，很容易拐到受傷，但這一次鞋子的包覆性提升，而且支撐性也變好，讓人迫不及待想要試跑看看！

{% asset_img 14-on-foot.jpg %}

行前有店員向大家介紹這雙鞋子並且解說，等等跑到皇居旁的區域時會進行一個接力。接下來就是大家輪流喊 1234，輪玩一圈後同數字即是同個組員。

{% asset_img 15-event-brief.jpg %}

在暖身的時候第一次體驗日本式的暖身口訣，有種在這裡上體育課的錯覺，非常新鮮的體驗！

{% asset_img 16-warmup.jpg %}

起跑後認識了一位來自奈良的つぐみ桑，他來東京出差，最近和朋友開始進行 Hyrox 的活動。剛好上週就是台北的 Hyrox 比賽，覺得非常巧，因為他也剛和朋友完成韓國的比賽。

接力起跑的地方剛好就是東京馬終點的附近。

{% asset_img 17-relay-start.jpg %}

因為剛完成東京馬，所以也沒辦法跑太快，但看著大家在寒冷的天氣裡接力還是非常熱血！幫忙組員拍影片記錄一下，不是為了得第一名僅僅是因為緣分聚在一起跑步，非常好玩！回程的路上太專心聊天，沒有看到地板突起差點跌倒，還好反應夠快沒有跌一大跤。

{% asset_img 18-running.jpg %}

{% asset_img 19-relay-team.jpg %}

活動結束回到店裡時店面已經打烊了，我們回到 B1。店員總結了一下今天的活動，並且說明現在買雲怪三會送東京限定毛巾。當下很心動，因為身為昂粉沒有看過這個商品，但想想目前鞋子真的有點多 QQ，所以還是理性消費了 XD。

{% asset_img 20-back-at-store.jpg %}

活動開始前和一位主管聊天，提到剛完成東京馬順便來參加這個活動。離開前這位主管拿著一條昂跑的毛巾說：

> 「這是慶祝你完成東京馬的禮物，祝福你！」

當下真的非常感謝這位大哥，謝謝大家舉辦這個活動，留下非常好的回憶！

{% asset_img 21-tokyo-towel.jpg %}

最後的最後，離開店前，店員出示著 QR Code 可以回饋今天的活動心得。完成後獲得了昂跑的跳繩，以及一張雲怪三的介紹卡。上面寫著到指定地點打卡，集滿數量後可以抽雲怪 3。此外四月底前出示這張卡片，都可以不用排隊直接進店。可說是一張 VIP 限定卡來著^0^

{% asset_img 22-vip-card.jpg %}
