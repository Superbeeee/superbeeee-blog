（第一篇在運筆的文章就獻給 On 跑班了哈）

身為一個超級 On 粉，一聽到有品牌跑班馬上就手刀報名！很幸運有通過書面來到第二關實體面試。當時補了更多品牌故事還有材質研究（身為 ONON Holding 股東還找到該材質台灣製造商 XDD）。而最後感謝可以順利獲選為訓練營的一員！

{% asset_img 02-camp-team.jpg %}

## 裝備包與費用

這個跑班最吸引人應該就是獲選後可以獲得 On 的裝備包括：On Performance 系列運動服飾、On 輕量排汗運動帽、On Cloudsurfer Next，全套總價值 $12,020 ＋ 十堂課程，而報名費是 $3,600 真的非常划算（客家人上線）。

## 訓練課程

{% asset_img 03-schedule.png %}

這十週的行程安排中，覺得最不容易的有：

- **第一堂的酷熱變黑測 5000**

{% asset_img 04-week1-5km.jpg %}

- **第五堂的安森暴雨定向越野**

{% asset_img 05-week5-orienteering.png %}

- **第六堂的劍中劍魔王坡**

{% asset_img 06-week6-hill.png %}

還有連續十週每週六都要五六點起床。但偉翔教練上課很有趣，助教也會時時刻刻關心學員，**情緒價值** 給好給滿，完全不覺得辛苦跟累！

{% asset_img 07-group-photo.jpg %}

除了上課內容最重要的應該就是教練開的課表。在第一堂測五千之後教練分了五組，自己被分在第三組。每週課表會根據不同的訓練內容調整。但因為後面有其他賽事，自己會有其他的課表做搭配。

{% asset_img 08-weekly-training.png %}

到了賽事前偉翔教練有為學員各自的狀況去預估完賽時間，自己當時的預估大概是落在 **「1:51-1:56」**。自己之前的 PB 是在 1:52，當時冬天吃好睡好狀態很好，不確定能不能突破，加上天氣如果很熱，自我懷疑感會好高。

## 比賽當天

到了比賽當天感覺真的不太妙。有點像是今年國家地理路跑的天氣，悶悶的，濕度也很高。

{% asset_img 09-race-day.jpg %}

跟跑班暖身完後準備開跑，結果當要過起始點的時候，手錶當機了，當下真的急了。「這麼熱沒有心律對照怎麼辦？」「配速看不到怎麼辦？」想說當作輕鬆跑欣賞風景的比賽，但一想到這段期間真的很努力練習，好想知道成果怎麼樣。好險在亂按按鈕一公里後手錶恢復正常，馬上調整好狀態，專注在比賽當下。

當天心率真的好高，也檢討了一下，是不是睡太少沒有休息好造成。在最後 2K 時遇到 NRC pacer，一直鼓勵自己，調整呼吸，撐著動作，還有拼命微笑看攝影師續命。

{% asset_img 10-finish-sprint.jpg %}

## 比賽成績

最後終點 **「1:48:03」** —— **「突破了自己，而且是冬天的自己。」** 突破自己也高於教練的預期，心中這樣想著，**跟自己比的感覺真的好好玩**。

{% asset_img 11-result.png %}

這個夏天真的太充實，充滿跑步的形狀。看著這個月的行程表，有點瘋，但是好好玩。

{% asset_img 12-month-schedule.png %}

## 致謝

也再次謝謝運筆還有昂跑團隊，很用心地規劃訓練營！雖然這次蠻辛苦的，但想到一句話：

**「馬拉松是銀河，跑者是星星。每個星星都是一個歷練，串起了人生。」**

成為每個自己最閃亮的星星吧🌟

## 後記 —— 品牌合作彩蛋

關於這次的戰服，沒錯，是 Loewe X On 的聯名。其實一直都知道兩家的合作，上個月已經是第六波合作。而在今年上半年第五波合作，出現驚為天人的改變 —— 就是兩家的 LOGO 竟然合體了！

{% asset_img 13-loewe-on-outfit.jpg %}

當時馬上打電話去各個櫃上詢問，才發現原來每個國家只有一櫃有實體展示，台灣則是 Loewe 微風南山店。當時買完真的不知什麼場合可以派上用場，結果發現 On 跑班的目標賽事真的再適合不過。

{% asset_img 14-loewe-on-logo.png %}

說起兩家品牌更深入的合作，也許淵源來自《挑戰者》這部電影。除了該電影以網球為主題，相關於 On 的網球線產品，2019 年費爺甚至加入品牌研究團隊。最重要的電影找來 Loewe 創意總監 Jonathan Anderson 擔任服裝設計師。

更有趣的是今年奧運 On 在巴黎設置了 LightSpray™ technology 展示驚人設計的 On Cloudboom Strike LS（也是今年波馬女冠 Hellen Obiri 所穿的原型鞋）。當時《挑戰者》的女主角 Zendaya 現身會場試穿，自己原以為可能只是路過吧，結果後來就宣布成為 On 的代言人了。

{% asset_img 15-cloudboom-strike-ls.jpg %}

{% asset_img 16-zendaya.jpg %}

前幾天上海和紐約的 On 也開啟了 LightSpray™ technology 的展示中心可以試穿（太羨慕嗚嗚）。

下半年還有有趣的賽事，繼續努力！如果有 On 的資訊，歡迎交流。
